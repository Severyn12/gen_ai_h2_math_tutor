Геометрія: Площі та теорема Піфагора
Площа прямокутника дорівнює добутку його довжини на ширину: S = a * b. Периметр прямокутника дорівнює P = 2(a + b). Площу вимірюють у квадратних одиницях, наприклад у квадратних сантиметрах.
Квадрат — це окремий випадок прямокутника з рівними сторонами, тому його площа S = a^2, а периметр P = 4a.
Площа трикутника дорівнює половині добутку основи на висоту: S = (a * h) / 2. Площа прямокутного трикутника дорівнює половині добутку його катетів: S = (a * b) / 2.
У прямокутному трикутнику квадрат гіпотенузи дорівнює сумі квадратів катетів: c^2 = a^2 + b^2. Цей результат називається теоремою Піфагора.
Звідси гіпотенузу знаходять як c = sqrt(a^2 + b^2), а невідомий катет — як a = sqrt(c^2 - b^2).
Діагональ прямокутника утворює прямокутний трикут із його сторонами, тому її довжина дорівнює d = sqrt(a^2 + b^2).
Справедливе й обернене твердження: якщо для сторін трикутника виконується c^2 = a^2 + b^2, то трикутник прямокутний.
Класичні приклади цілих сторін (піфагорові трійки): 3, 4, 5; 5, 12, 13; 8, 15, 17; 7, 24, 25. Наприклад, якщо катети дорівнюють 3 і 4, то гіпотенуза дорівнює 5.
