Алгебра: Лінійні та квадратні рівняння
Лінійне рівняння з однією змінною має вигляд ax + b = c, де a не дорівнює нулю. Щоб знайти x, переносять вільні члени в одну частину рівняння, а члени зі змінною — в іншу, після чого ділять на коефіцієнт біля x. Загальний розв'язок: x = (c - b) / a.
Наприклад, для рівняння 3x + 2 = 11 маємо 3x = 9, тобто x = 3. Знайдений корінь варто перевірити, підставивши його назад у рівняння.
Якщо змінна стоїть в обох частинах, її члени спершу збирають в одній частині. Якщо в рівнянні є дужки, їх розкривають, а якщо дроби — обидві частини множать на спільний знаменник.
Якщо після перетворень змінна зникає і рівність хибна (наприклад 0 = 5), рівняння не має розв'язків. Якщо ж рівність істинна (0 = 0), розв'язків безліч.
Квадратне рівняння має вигляд ax^2 + bx + c = 0, де a не дорівнює нулю. Дискримінант обчислюється за формулою D = b^2 - 4ac. Якщо D > 0, рівняння має два різні дійсні корені. Якщо D = 0, рівняння має один подвійний корінь. Якщо D < 0, дійсних коренів немає.
Формула коренів квадратного рівняння: x = (-b ± sqrt(D)) / (2a).
Неповні квадратні рівняння розв'язують простіше. Рівняння ax^2 + c = 0 дає x = ± sqrt(-c / a), якщо -c / a не від'ємне. Рівняння ax^2 + bx = 0 розкладають як x(ax + b) = 0, звідки x = 0 або x = -b / a.
За теоремою Вієта для зведеного рівняння x^2 + px + q = 0 сума коренів дорівнює -p, а добуток коренів дорівнює q. Це дає змогу швидко добирати цілі корені та розкладати квадратний тричлен на множники: ax^2 + bx + c = a(x - x1)(x - x2).
Наприклад, рівняння x^2 - 5x + 6 = 0 має корені 2 і 3, бо 2 + 3 = 5 і 2 * 3 = 6.
Інший метод — виділення повного квадрата: x^2 + bx = (x + b/2)^2 - (b/2)^2.
